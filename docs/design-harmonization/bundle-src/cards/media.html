OptimizedImage — the load sequence

1 — blurDataUrl under a backdrop-blur-2xl layer
2 — the real file arrives at opacity-0
3 — opacity-100 after transition-opacity duration-300
no blurDataUrl — a flat bg-primary/10 stands in

Box is relative overflow-hidden with an inline aspectRatio: "{width} / {height}", so layout never shifts. A srcSet is built across RESPONSIVE_IMAGE_WIDTHS at the caller's aspect ratio; fit defaults to cover. If the browser had the file cached, a mount effect reads img.complete and skips the fade.

CoverImage — with and without a picture

image present — 1080×720, aspect-3/2
no image — the drawn placeholder

The placeholder is two concentric circles on bg-primary/10: an outer w-1/4 min-w-10 rounded-full border-2 border-primary/35 ring around an inner w-2/3 border border-primary/20 — a plate, drawn in CSS, that scales with the box. It takes role="img" and the alt as aria-label, unless the alt is empty, in which case it goes aria-hidden.
