Mapped classes — toast bg-background text-foreground border-border shadow-lg · description text-foreground/65 · actionButton bg-primary text-primary-foreground · cancelButton bg-card text-foreground/65. Sonner supplies the radius, width and icons; only colour is ours.

Two ways in

Redirect toast — server redirectWithToast(path, { title, description?, type }) flashes the toast into the session; useToast in the root layout replays it after hydration. Used for signup success, settings changes, deletes.
Direct toast — client toast.success(…) straight from a fetcher effect, for actions that never navigate — sending an invite, renaming yourself, revoking other sessions.
