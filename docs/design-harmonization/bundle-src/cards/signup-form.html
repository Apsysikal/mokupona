Honeypot — a field that must never be seen

HoneypotField renders two labelled inputs plus a <style>.__honeypot_inputs { display: none }</style> inline with the markup, so the trap can never flash visible before CSS loads.

It deliberately avoids sr-only — an announced field is one a real user would fill in. The visible labels are the escape hatch for anyone who sees it anyway. A trapped submission gets the success toast and redirect, so a bot never learns it was caught.
