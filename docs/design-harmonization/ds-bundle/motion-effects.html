Foundations

Motion & effects

Four custom utilities carry every non-trivial effect in the app: glow-primary / glow-primary-strong, animate-page-in, scrollbar-hidden, and the two accordion keyframes. Everything else is a plain transition-colors at the default 150ms; only two places lengthen it — the chevron rotate and the seat bar fill.

Glow — the only decorative gradient

glow-primary — 0.15 alpha
glow-primary-strong — 0.20 alpha

Rendered by <Glow strong? />: a pointer-events-none absolute rounded-full div, positioned by the caller. Used behind the auth split, the mobile menu, and the dinners empty state. Elevation is borders, never shadows — the only shadow-lg left is on the Radix dialog and popover portals.

animate-page-in — every admin route body

Overview

fades up 0.5rem over 300ms

opacity 0 → 1 and translateY(0.5rem) → 0, 300ms ease-out. Applied once per route, on the outermost admin div.

scrollbar-hidden — horizontal rails on small screens

all upcoming past basics menu & donation schedule & pricing

scrollbar-width: none + ::-webkit-scrollbar { display: none }. Used by AdminTabs and SectionNav, which collapse to a scroll rail below md.

Focus — one recipe

Buttons and the checkbox take an outer focus-visible:ring-2 ring-ring; field shells take focus-visible:inset-ring-2 with the border dropped, so the control never grows on focus. No component defines a third treatment.
