Type ramp

Rulings

Line-height: the utilities' built-in values (text-5xl is already leading-none) — the five custom tight leadings and both body leadings are deleted.
Tracking: one value, native tracking-tight (−0.025em) on display text — absorbs −0.01em and −0.02em.
Weight: font-light for the display family in both registers — the admin font-extrabold headings converge onto it. font-semibold is body-level emphasis (buttons, card-row titles), also register-independent.
md ladder: each role steps up exactly one native size at md — 2xl→3xl, 3xl→4xl, 4xl→5xl — keeping the three roles distinct at every breakpoint.
