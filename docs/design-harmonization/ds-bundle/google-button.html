Google sign-in

The one component that deliberately does not use our tokens. Google's brand guidelines fix the surface (#131314), border (#8e918f), text (#e3e3e3) and letter-spacing, so the button hard-codes them — it only borrows our radius, height and focus ring so it still sits in a form. The divider above it is part of the same component.

GoogleSignInButton — divider and button

or

Divider is aria-hidden — "or" is visual sequencing, not content. Button is h-12 w-full rounded-lg text-sm font-medium tracking-[0.25px]; the tracking-[0.25px] and font-medium are the only arbitrary type values left in the codebase, and they are Google's, not ours. Focus and disabled still follow our recipe: focus-visible:ring-2 ring-ring, disabled:opacity-50.
