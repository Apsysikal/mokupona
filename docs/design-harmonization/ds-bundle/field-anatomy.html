Forms

Field anatomy

Four wrappers — Field, TextareaField, SelectField, CheckboxField — share one useFieldIds hook that generates the id, wires aria-describedby to both the description and the error list, and merges rather than overwrites whatever Conform already put there. Every field is a flex flex-col gap-2 stack in the same order: label, description, control, errors.

States

Focus drops the border and paints an inset-ring-2 ring-ring, so nothing reflows. Disabled is cursor-not-allowed opacity-50 on every control type. Invalid fields carry aria-invalid but no colour of their own — the error list below them is the signal.
