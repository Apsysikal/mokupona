AdminDeleteButton

idle · in flight · blocked

A fetcher.Form posting to a dedicated …/delete route, so a row deletes without navigating. It disables itself while fetcher.state !== "idle" and swaps its label to "Deleting…". Always size="sm" variant="destructive-outline" — the filled destructive is reserved for confirmation screens.
