List field (friends)

The one repeater in the public form: a guest adds friends up to a configured maximum, each answering the same set of sub-fields. It opens with a full-width hairline instead of a label row, because it is a section break in the form rather than another field. Add and remove are Conform intent buttons, so the whole thing works without JavaScript.
