# Component inventory — codebase → design system

Every component in the app, and the [ds-bundle](./ds-bundle/) card that documents it.
Generated by reading `app/components/**`, `app/features/**` and `app/routes/**` on
2026-08-18. When a component moves or a new one lands, add the row and the card together.

Open [ds-bundle/index.html](./ds-bundle/index.html) to browse the cards; in Claude Design
they are grouped by the `@dsCard group=` marker in each card's first line.
